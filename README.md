# PRAKTIKUM-PEMMOB-1
Materi yang Dipelajari:Material Design 3: 
1. Mengonfigurasi palet warna, 
2. gaya tulisan (tipografi)
3. dan tema statis agar desain aplikasi tetap konsisten.  

Navigasi Halaman: 
Menghubungkan dan berpindah antar halaman aplikasi menggunakan NavHost dan NavController di dalam MainActivity.  

Komponen UI & Form: 
Menyusun antarmuka menggunakan Scaffold, Card, dan membuat kotak isian teks dengan OutlinedTextField.  

State & Interaksi: 
Menangkap ketikan pengguna menggunakan mutableStateOf dan menampilkan pesan notifikasi singkat (Snackbar) dengan eksekusi asinkronus (Coroutine) saat tombol ditekan.
